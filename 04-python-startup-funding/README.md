# Исследование финансирования стартапов

Аналитический проект на **Python**: исследование исторических данных о
венчурном финансировании стартапов для инвестиционной компании, оценивающей
выход на рынок покупки и развития компаний.

## Задача

Финансовая компания, работающая с венчурными инвестициями, хочет понять
закономерности финансирования стартапов и оценить перспективы выхода на рынок.
На исторических данных нужно исследовать динамику и структуру финансирования и
ответить на вопросы, важные для оценки инвестиционных стратегий.

В рамках проекта:

- предобработка данных: дубликаты, пропуски, корректность числовых и временных
  значений;
- группировка компаний по срокам финансирования и сравнение групп по числу и
  объёму инвестиций;
- классификация сегментов рынка на массовые, средние и нишевые;
- поиск типичных и аномальных объёмов финансирования, исключение выбросов и
  ограничение периода исследования;
- сравнение популярности и объёмов разных типов финансирования;
- анализ динамики раундов и объёмов инвестиций по годам;
- расчёт доли возврата средств по типам финансирования и оценка её
  устойчивости;
- итоговые выводы и рекомендации: куда и как было бы целесообразно
  инвестировать, «если бы на дворе был 2015 год».

## Данные

Исследование опирается на две таблицы.

**`cb_investments`** — компании и состоявшееся финансирование. Основные группы
полей:

- **О компании:** `name`, `homepage_url`, `category_list` (категории через `|`),
  `market`, `status`, `country_code`, `state_code`, `region`, `city`.
- **Основание:** `founded_at`, `founded_month`, `founded_quarter`,
  `founded_year`.
- **Финансирование в целом:** `funding_total_usd`, `funding_rounds`,
  `participants`, `first_funding_at`, `mid_funding_at`, `last_funding_at`.
- **Суммы по типам инвестиций:** `seed`, `venture`, `equity_crowdfunding`,
  `undisclosed`, `convertible_note`, `debt_financing`, `angel`, `grant`,
  `private_equity`, `post_ipo_equity`, `post_ipo_debt`, `secondary_market`,
  `product_crowdfunding`.
- **Суммы по раундам:** `round_A` … `round_H`.

**`cb_returns`** — объёмы возвратов по годам и типам финансирования (в млн $):
`year` и суммы возвратов по каждому типу инвестиций (`seed`, `venture`,
`equity_crowdfunding`, `undisclosed`, `convertible_note`, `debt_financing`,
`angel`, `grant`, `private_equity`, `post_ipo_equity`, `post_ipo_debt`,
`secondary_market`, `product_crowdfunding`).

> Данные предоставлены Яндекс Практикумом и недоступны публично, поэтому
> ноутбук не перезапускается «с нуля». Все результаты и графики сохранены
> в файле и отображаются прямо на GitHub.

## Что внутри

Ноутбук [`startup_funding_analysis.ipynb`](startup_funding_analysis.ipynb)
со структурой: знакомство и предобработка → инжиниринг признаков (группы по
срокам, сегменты рынка) → работа с выбросами и анализ типов финансирования →
анализ динамики по годам и доли возвратов → итоговые выводы и рекомендации.

## Инструменты и приёмы

- **pandas** — очистка, объединение таблиц, группировки и агрегации
- **matplotlib / seaborn** — визуализация динамики и структуры финансирования
- Инжиниринг признаков: группы по срокам финансирования, сегментация рынка
  (массовые / средние / нишевые)
- Работа с выбросами: поиск аномалий, отсечение по границам, ограничение
  периода
- Анализ временных рядов: динамика раундов, объёмов и доли возвратов по годам
