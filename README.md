# Портфолио аналитика данных — Екатерина 

Привет! Я начинающий аналитик данных. В этом репозитории собраны мои проекты
по SQL, Python и визуализации данных — от исследовательского анализа и очистки
данных до дашбордов и бизнес-выводов.

**О себе:** прошла курс аналитики данных в Яндекс Практикуме. Умею доставать
данные из БД на SQL, анализировать их в Python (pandas, matplotlib/seaborn) и
собирать интерактивные дашборды в DataLens. Ищу позицию стажёра или junior-аналитика.

## Стек и навыки

- **SQL (PostgreSQL):** сложные выборки, `JOIN`, агрегаты, оконные функции,
  CTE, `PERCENTILE`, работа с датами, очистка выбросов
- **Python:** pandas, matplotlib, seaborn, phik — предобработка,
  исследовательский анализ, визуализация, инжиниринг признаков
- **Подход:** формулирую бизнес-вопрос, проверяю данные, довожу до выводов и
  рекомендаций
