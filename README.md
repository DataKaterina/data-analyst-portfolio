# Портфолио аналитика данных — Екатерина Дорохина 

Привет! Я начинающий аналитик данных. В этом репозитории собраны мои проекты по SQL, Python, статистике и визуализации данных — от исследовательского анализа и очистки данных до проверки гипотез, A/B-тестов, дашбордов и бизнес-выводов.

**О себе:** прошла курс аналитики данных в Яндекс Практикуме. Умею доставать данные из БД на SQL, анализировать их в Python (pandas, matplotlib/seaborn), проверять гипотезы и оценивать A/B-тесты, собирать интерактивные дашборды в DataLens. Отдельная сильная сторона — опыт в управлении и маркетинге: понимаю бизнес-метрики (unit-экономика, ROMI, CAC, LTV) и довожу анализ до рекомендаций. Ищу позицию стажёра или junior-аналитика.

## Стек и навыки

- **SQL (PostgreSQL):** сложные выборки, `JOIN`, агрегаты, оконные функции,
  CTE, `PERCENTILE`, работа с датами, очистка выбросов
- **Python:** pandas, matplotlib, seaborn, phik — предобработка,
  исследовательский анализ, визуализация, инжиниринг признаков
- **Статистика:** проверка гипотез (тест Манна — Уитни, Z-тест пропорций), A/B-тестирование, расчёт размера выборки
- **Визуализация и BI:** Yandex DataLens (дашборды, фильтры, параметры, вычисляемые поля), Google Sheets
- **Подход:** формулирую бизнес-вопрос, проверяю данные, довожу до выводов и
  рекомендаций
