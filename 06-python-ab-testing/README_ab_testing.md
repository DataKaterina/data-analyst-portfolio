# Проверка гипотез и анализ A/B-теста

Аналитический проект на **Python**: статистическая проверка гипотезы о
поведении пользователей и оценка результатов A/B-теста. Проект состоит из двух
независимых частей.

## Часть 1. Проверка гипотезы о вовлечённости пользователей

**Задача.** Сравнить вовлечённость пользователей двух городов (Москва и
Санкт-Петербург) в сервисе для чтения и прослушивания книг. Проверить
гипотезу, что пользователи Санкт-Петербурга в среднем проводят в сервисе
больше времени, с помощью односторонней проверки для двух выборок:

- **H₀:** среднее время активности в Санкт-Петербурге не больше, чем в Москве.
- **H₁:** среднее время активности в Санкт-Петербурге больше, и различие
  статистически значимо.

**Данные.** Выгрузка активности пользователей книжного сервиса за осень
2024 года. Исходные таблицы охватывают сессии чтения и прослушивания
(длительность, платформа, дата, версия приложения, тип контента), сам контент
(тип, жанры, длительность, автор) и географию (город, регион, страна). Для
этой части используется агрегат по пользователю: город, идентификатор
пользователя и суммарное время активности в часах.

**Что сделано:**
- предобработка: удаление дубликатов, поиск и отсев пользователей,
  встречающихся в обоих городах, отсечение выбросов по 99-му перцентилю;
- сравнение групп по описательным статистикам и распределению;
- выбор теста с обоснованием: распределение сильно скошено (std ≫ mean),
  поэтому выбран непараметрический **тест Манна — Уитни** вместо t-теста;
- аналитическая записка с интерпретацией результата.

**Результат.** p-value = 0.43 → нулевая гипотеза не отвергается.
Статистически значимой разницы в активности пользователей двух городов не
обнаружено: средние и медианы близки, а индивидуальный разброс внутри городов
многократно превышает межгородские различия.

## Часть 2. Анализ результатов A/B-теста

**Задача.** Интернет-магазин геймифицированных товаров для здорового образа
жизни упростил интерфейс сайта и протестировал новую версию на части
аудитории. Гипотеза теста: за 7 дней после регистрации конверсия в покупку
вырастет минимум на 3 процентных пункта. Нужно оценить корректность
проведения теста и проанализировать результаты.

**Данные.** Две таблицы. Таблица участников: идентификатор пользователя,
группа теста (A — контрольная, B — новый интерфейс), название теста,
устройство регистрации. Таблица событий за декабрь 2020 года: идентификатор
пользователя, дата и время события, тип события (регистрация, вход, просмотр
товара, покупка) и дополнительное поле с деталями.

**Что сделано:**
- проверка корректности теста: соответствие ТЗ, равномерность распределения по
  группам, пересечения с конкурирующим тестом;
- определение горизонта анализа — события первых 7 дней после регистрации;
- оценка достаточности выборки через расчёт минимального размера (мощность 80%,
  достоверность 95%, базовая конверсия 30%, MDE 3 п.п.);
- проверка различия конверсий **Z-тестом пропорций**.

**Результат.** p-value = 0.02 → нулевая гипотеза отвергается: конверсия в
группе с новым интерфейсом статистически значимо выше (29% против 27%, прирост
2 п.п.). Эффект значим, но оказался меньше заложенного в тест ожидаемого
(3 п.п.).

## Инструменты и приёмы

- **pandas** — предобработка, группировки, объединение таблиц
- **matplotlib** — визуализация распределений
- **scipy.stats** — тест Манна — Уитни
- **statsmodels** — Z-тест пропорций, расчёт размера выборки (`NormalIndPower`)
- Осознанный выбор критерия в зависимости от распределения данных
- Полный цикл проверки гипотез: формулировка H₀/H₁, выбор теста, уровень
  значимости, интерпретация p-value
