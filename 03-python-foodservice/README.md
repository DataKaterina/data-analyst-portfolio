# Исследование рынка общественного питания Москвы

Аналитический проект на **Python**: исследовательский анализ рынка заведений
общепита Москвы для инвесторов, выбирающих формат и локацию нового заведения.
От загрузки и очистки данных до визуализаций и рекомендаций заказчику.

## Задача

Инвесторы из фонда «Shut Up and Take My Money» планируют открыть заведение
общественного питания в Москве. Формат (кафе, ресторан или бар), расположение,
меню и цены ещё не определены. Нужно провести исследовательский анализ рынка
Москвы, результаты которого помогут заказчику выбрать подходящее место и
концепцию.

## Данные

Исследование опирается на два файла. Они объединены в единый датафрейм; проведена
предобработка — приведение типов, обработка пропусков, поиск явных и неявных
дубликатов.

**`rest_info.csv`** — информация о заведениях:

| Поле | Описание |
|------|----------|
| `name` | название заведения |
| `address` | адрес |
| `district` | административный округ (например, Центральный административный округ) |
| `category` | категория заведения (кафе, пиццерия, кофейня и т. д.) |
| `hours` | дни и часы работы |
| `rating` | рейтинг по оценкам пользователей Яндекс Карт (максимум 5.0) |
| `chain` | признак сетевого заведения: `0` — несетевое, `1` — сетевое (для мелких сетей возможны ошибки) |
| `seats` | количество посадочных мест |

**`rest_price.csv`** — информация о среднем чеке:

| Поле | Описание |
|------|----------|
| `price` | ценовая категория (средние, ниже среднего, выше среднего и т. д.) |
| `avg_bill` | средняя стоимость заказа в виде строки-диапазона (например, «Средний счёт: 1000–1500 ₽», «Цена чашки капучино: 130–220 ₽») |
| `middle_avg_bill` | числовая оценка среднего чека — только для строк `avg_bill`, начинающихся со «Средний счёт»: медиана диапазона, либо одно число, иначе пусто |
| `middle_coffee_cup` | числовая оценка цены чашки капучино — только для строк, начинающихся с «Цена одной чашки капучино»: медиана диапазона, либо одно число, иначе пусто |

> Данные предоставлены Яндекс Практикумом и недоступны публично, поэтому
> ноутбук не перезапускается «с нуля». Все результаты и графики сохранены
> в файле и отображаются прямо на GitHub.

## Что внутри

Ноутбук [`foodservice_market_moscow_python.ipynb`](foodservice_market_moscow_python.ipynb)
со структурой: загрузка и знакомство с данными → предобработка →
исследовательский анализ (8 задач с визуализациями) → итоговые выводы и
рекомендации.

## Инструменты и приёмы

- **pandas** — очистка, объединение таблиц, группировки и агрегации
- **matplotlib / seaborn** — визуализации (гистограммы, boxplot, круговые и
  столбчатые диаграммы)
- **phik** — корреляция для разнотипных признаков
- Работа с пропусками, явными и неявными дубликатами, выбросами
- Осознанный выбор медианы vs среднего в зависимости от распределения

## Ключевые выводы

- На рынке преобладают **кафе, рестораны и кофейни**; больше всего заведений
  и самое широкое разнообразие категорий — в **Центральном административном
  округе**.
- Большинство заведений **несетевые**. Среди сетей лидирует «Шоколадница»
  (120 точек); в топе преобладают кофейни и пиццерии со средним рейтингом
  3,9–4,4.
- Типичная вместимость — **50–80 мест**; распределение с длинным правым
  хвостом (отдельные заведения на 500+ мест).
- **Средний чек снижается по мере удаления от центра**: максимум в ЦАО
  (~1200 ₽), минимум в ЮВАО (~650 ₽).
- Рейтинг заведения **не имеет выраженной зависимости** ни от одного из
  рассмотренных признаков (самая сильная связь — с ценовой категорией, и та
  слабая).

## Рекомендации заказчику

Центральный округ подходит для заведений среднего и высокого ценового
сегмента; в удалённых районах разумнее ориентироваться на доступные цены.
При оценке конкуренции важно учитывать не только сетевые кофейни и пиццерии,
но и большое число несетевых заведений.
